# 「例を読み込む」に並べるミッション

上のバーの「…」→「例を読み込む」で読めるミッション。中身は**保存ファイルとまったく同じ形**で、
読み込みも通常の「読込」と同じ道 (`js/mission/mission_file.js` の `loadMissionData`) を通る。

## 中身

| | |
|---|---|
| `index.json` | 一覧に出す名前・説明・解説ページへの入口 |
| `<id>.json` | ミッション本体 (保存ファイルと同じ形) |

## どこから来たか

`tools/make_examples.py` が作る。**手で編集しない。**

ヘルプ (`docs/`) に載せている軌道と同じものが出るようにしてあり、作り方は2通り。

- **台本を走らせて作るもの** (チュートリアル①〜⑤、面を折って木星へ) …
  図を撮るのと同じ台本 (`tools/docs_scenarios.py`) を最後まで走らせて、出来上がった
  ミッションを書き出す。チュートリアルの手順を直せば、例も一緒に直る。
- **固めた設計をそのまま使うもの** (ΔVEGA・VEGA・VEEGA) …
  資料の図と本文が使っている設計 (`tools/docs_missions.py`) をそのまま置く。

つまり、ここから読み込んだ軌道の成績は資料に載っている数字と一致する。
ただし④は台本の中で自動調整を通るので、作り直すたびに最後の桁がわずかに動く
(自動調整は打ち切り時間で結果が決まるため)。

## 作り直す

アプリを静的サーバで配っておいて (中身は何でもよい)、

```
python tools/make_examples.py http://127.0.0.1:8421/index.html
```

チュートリアルの台本はポークチョップ図や自動調整を通るので、全部で10分ほどかかる。
